# projetoDeBaixoParaCima

Aqui eu coloco uma pequena descrição sobre o projeto.

## Nível 2 - posso falar dos requisitos

Como requisitos do projeto:

- nodejs
- npm
- express
- e muita loucura

## Nível 2 - posso falar de como rodar o projeto

Para rodar o projeto, siga os seguintes passos:

```bash
npm install
npm start
```

### Nível 3 - posso falar de como rodar o projeto em modo de desenvolvimento

Para rodar o projeto em modo de desenvolvimento, siga os seguintes passos:

```bash
npm install
npm run dev
```
